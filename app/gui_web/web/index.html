Esto es el buffer real de stdout/stderr de DexRelay -- hasta 500 líneas, se van descartando las más viejas. No hay "Nivel"/"Fuente" por línea todavía porque DexRelay no tiene un módulo de logging estructurado, solo print(). Las líneas en rojo vienen de stderr (normalmente, una excepción no capturada); el resto es stdout. "Limpiar" vacía el buffer en memoria, no borra nada de disco.
